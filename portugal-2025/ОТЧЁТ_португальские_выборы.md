# Парламентские выборы Португалии 2025: открытые данные

**Выборы:** досрочные выборы в Ассамблею Республики (Assembleia da República), **18 мая 2025** — последние парламентские выборы на текущий момент (следующие — не ранее 2028; президентские были в январе 2026).

## TL;DR — что открыто и скачано

| Уровень детализации | Есть ли официальные данные? | Где |
|---|---|---|
| Страна / округа (círculos, 22 шт.) | ✅ XLSX/ODS + PDF | CNE |
| Муниципалитеты (concelhos, 308) | ✅ JSON | Портал результатов MAI |
| Приходы (freguesias, **3092**) | ✅ JSON — **самый детальный официальный уровень** | Портал результатов MAI |
| Заграница: страны и консульства | ✅ JSON (Европа / вне Европы) | Портал результатов MAI |
| **Участки (secções de votação)** | ⚠️ централизованно **нет**, но есть у муниципалитетов (PDF «MAPA GLOBAL POR SECÇÃO DE VOTO») | сайты câmaras municipais — см. раздел «Данные по участкам: где качать» |

По участкам (секциям): MAI/SGMAI публикует результаты только до прихода — проверено и на нашей выгрузке AR-2025 (3092 фрегезии — листья дерева), и на самом новом API портала (президентские-2026: фрегезия `final: true`, детей нет), и на официальной таблице SGMAI `AR_2025_Globais.xlsx` (листы до Freguesia/Consulado, без секций). Секционные данные публичны **на уровне муниципалитетов** — камеры публикуют «MAPA GLOBAL POR SECÇÃO DE VOTO» по каждому голосованию; для AR-2025 проверено на живом примере (Alcácer do Sal, скачан и распарсен). Где именно качать — раздел «Данные по участкам (secções): где и что качать» ниже. Подсчёт при этом по закону идёт именно по участкам — правовая база и статьи LEAR: раздел «Правовая база подсчёта голосов» ниже.

## Источники

### 1. Официальный портал результатов MAI/SGMAI (главный источник)
- Портал: <https://www.eleicoes.mai.gov.pt/> — все выборы с 1979 по 2026 (AR, президентские, европейские, муниципальные, региональные, референдумы)
- Раздел AR 2025: <https://www.eleicoes.mai.gov.pt/legislativas2025/>
- Это Angular-SPA, данные лежат открытыми JSON по схеме:
  - `…/legislativas2025/assets/static/territory-results/territory-results-<KEY>-AR.json` — результаты территории (страна/округ/муниципалитет/приход, загран. округа и консульства), включая `previousResults` (итоги 2024 для сравнения)
  - `…/assets/static/territory-children/territory-children-<KEY>.json` — дерево территорий
  - `…/assets/static/configurations.json`, `affluences.json` (явка по времени), `results-available.json`
- Ключи территорий: `GLOBAL-990000` (итог), `LOCAL-500000` (страна), `LOCAL-0X0000` (округа), `LOCAL-0XYZ00` (муниципалитеты), `LOCAL-0XYZAB` (приходы), `FOREIGN-8xxxxx/9xxxxx` (Европа/вне Европы → страны → консульства)
- SGMAI публикует **официальные таблицы (XLSX) по годам** на странице
  <https://www.sg.mai.gov.pt/pt/AdministracaoEleitoral/Resultadoseleitorais/> —
  AR-2025: [AR_2025_Globais.xlsx](https://www.sg.mai.gov.pt/pt/AdministracaoEleitoral/EleicoesReferendos/AssembleiaRepublica/Documents/AR2025/AR_2025_Globais.xlsx)
  (листы: Global / Distrito-RA / Concelho / Freguesia / País / Consulado — **до фрегезии, секций нет**);
  там же XLS/XLSX за 1999–2024 и аналогичные разделы по президентским и муниципальным выборам.
  Тот же файл сохранён локально: `data/seccoes_test/AR_2025_Globais.xlsx`.
- ⚠️ У более новых выборов (проверено на президентских-2026) другой шаблон URL — числовые id вместо KEY:
  `…/<slug>/assets/static/territory/children-electionId=61-territoryId=<ID>.json` и
  `…/assets/static/result/territory-electionId=61-territoryId=<ID>-organId=3.json` (id фрегезии — листовые, секций нет).
- ⚠️ CDN (Akamai) агрессивно блокирует массовые загрузки: держите ≤2–3 запроса/сек, при «Access Denied» — пауза 1–2 мин. Скрипт ниже это учитывает.

### 2. CNE (Комиссия по выборам) — официальные итоги
- Страница результатов AR 2025: <https://www.cne.pt/content/eleicoes-referendos-resultados-oficiais>
- **Excel/ODS по округам (официальный «mapa»):** <https://www.cne.pt/sites/default/files/dl/eleicoes/2025_ar/docs_geral/2025_ar_mapa_resultados.zip> (xlsx+ods; лист: 22 округа × партии, inscritos/votantes/brancos/nulos)
- **Официальная карта результатов (PDF, Diário da República, Mapa Oficial n.º 2-A/2025):** <https://www.cne.pt/sites/default/files/dl/eleicoes/2025_ar/2025_ar_mapa_oficial_dr.pdf>

## Правовая база подсчёта голосов (проверено по официальным текстам законов)

Базовый закон — **Lei n.º 14/79, de 16 de maio «Lei Eleitoral para a Assembleia da República» (LEAR)**,
консолидированная редакция от 23-07-2026 (PDF, 53 стр., скачан в `data/legislacao/`).
Регистрация избирателей — **Lei n.º 13/99** (старый закон 13/79 давно отменён — частая путаница).

- LEAR, консолидированный PDF (CNE): <https://www.cne.pt/sites/default/files/dl/legis_lear_consolidada_2026-07.pdf>
- LEAR, оригинал 1979 в Diário da República (ELI-ссылка): <https://data.dre.pt/eli/lei/14/1979/05/16/p/dre/pt/html>
- Lei 13/99, консолидированный PDF (CNE): <https://www.cne.pt/sites/default/files/dl/legis_13_99_re_2024-02-08.pdf>
- Сводная страница избирательного законодательства CNE: <https://www.cne.pt/content/legislacao-eleitoral>

### Цепочка подсчёта по закону (статьи LEAR, цитаты в переводе)

| Шаг | Статья | Что установлено |
|---|---|---|
| Участки | ст. 40.º | «Каждой фрегезии соответствует одно assembleia de voto»; при числе избирателей **заметно больше ~1000** оно делится на **secções de voto** (решение муниципалитета) |
| Подсчёт на участке | ст. 100.º–102.º | После закрытия: счёт проголосовавших по спискам, вскрытие урны, пересчёт бюллетеней; каждый бюллетень **оглашается вслух**; председатель делает контрпроверку; результаты немедленно публикуются **эдиктом на двери** участка (голоса по каждой lista, белые, недействительные) |
| Протокол участка | ст. 105.º | **Acta das operações eleitorais** обязана содержать: всех inscritos и votantes; голоса по каждой lista; белые; недействительные; номера досрочно проголосовавших; разногласия счёта |
| Передача наверх | ст. 106.º | В течение 24 часов акты всех участков передаются в окружную **assembleia de apuramento geral** |
| Окружной подсчёт | ст. 108.º–111.º | Окружная комиссия (председатель — судья, +2 юриста, +2 профессора математики, +6 председателей участков) сводит **акты участков**, проверяет спорные бюллетени, распределяет мандаты; срок — до 10-го дня после выборов. **Фрегезии как ступени подсчёта здесь нет** |
| Национальная карта | ст. 115.º | **CNE** публикует в Diário da República официальную карту по округам. Наш `2025_ar_mapa_oficial_dr.pdf` (Mapa Oficial n.º 2-A/2025 от 31-05-2025) дословно открывается: «Nos termos do artigo 115.º da Lei n.º 14/79… a Comissão Nacional de Eleições faz publicar…» |
| Досрочное голосование | ст. 79.º-C-15/16, 87.º | Конверты досрочного голосования (включая «мобильное» за 7 дней до выборов) доставляются в **участок по месту регистрации** избирателя и в день выборов опускаются в его урну → учитываются в акте этого участка |
| Заграница | ст. 101.º-A, 106.º-B–J | За рубежом голосуют преимущественно по почте; конверты считаются отдельными «assembleias de recolha e contagem» **на 10-й день после выборов** в помещениях SGMAI в Португалии, затем — загран. окружная apuramento geral. Отсюда ~10-дневный срок финальных итогов |

Поправки к распространённым неточностям (в т.ч. к моей первой версии): порог деления на секции —
**~1000** избирателей (не 1600); национальную карту издаёт **CNE** («CNAP» — устаревшее название
упразднённого органа); окружной орган в действующей редакции — **assembleia de apuramento geral**
(историческое название CTAP).

### Эмпирическая сверка с нашими данными (`results_all.csv`)

- Все **20 округов на территории страны: итог округа = сумме его приходов точно** (Δ = 0 по
  избирателям, явке, белым, недействительным).
- Национальный итог = приходы + загран. округа, до голоса:
  5 965 446 (фрегезии) + 255 305 (Europa) + 97 198 (Fora da Europa) = **6 317 949**.
- Вывод: данные портала на уровне фрегезий покрывают 100% голосов внутри страны, а заграничные
  голоса через фрегезии не проходят — ровно как предписывает закон (отдельный подсчёт).

### Что это даёт для вопроса об участках (secções)

Юридически минимальная единица подсчёта — **участок**: у каждого публичный счёт, эдикт на двери и
акта с полными результатами (ст. 100–105). «Подсчёта внутри фрегезий» как отдельной процедуры не
существует — фрегезия лишь география участка и уровень публикации портала. Данные по каждой секции
у государства есть с необходимостью (окружные итоги собираются именно из актов секций, ст. 106 и
109) — сильный аргумент при запросе выгрузки по секциям в SGMAI (Lei 26/2016).

## Обсуждения «почему нет данных по секциям» и попытки доступа (проверено 09.10.2026)

**Коротко: публичных обсуждений «закрытия» и официального объяснения не найдено; зато найден
обходной путь — муниципальные карты по секциям.**

- **Reddit** (r/portugal и соседние, поиск по архиву pullpush.io, фразы «secções de voto»,
  «resultados por secção», «dados eleitorais secção»): обсуждений доступа к секционным данным нет.
  Ближайшее релевантное — жалоба 2026 г., что на портале отсутствуют результаты 2-го тура
  ([тред](https://www.reddit.com/r/portugal/comments/1r1fg8k/)). Оговорка: архив покрывает не всё,
  свежие ветки (2024–2026) могут отсутствовать.
- **YouTube** (парсинг выдачи по «resultados por secção eleições», «secção de voto Portugal»):
  только ролики о процедуре голосования и новостные сюжеты; темы публикации данных нет.
- **Форумы**: специализированных португальских форумов по электоральным данным не выявлено —
  обсуждения живут в Facebook/X, ретроспективно недоступных.
- **CADA** (мнения по жалобам — прямая проверка «кто пытался»): поиск по cada.pt не работает для
  автоматических запросов (редирект на главную), старая платформа запросов pedidos.sgc.ma.gov.pt
  мертва и в архивах не сохранилась. Проверить, были ли запросы о секциях, пока не удалось.
- **Муниципальные карты по секциям (главная находка).** Câmara Municipal публикуют собственные
  «MAPA GLOBAL POR SECÇÃO DE VOTO» — официально, в разрезе фрегезия × секция × партия. Пример —
  Сабугал (округ Guarda):
  - AR-2024 (10.03.2024): [карта по секциям](https://arquivo.pt/wayback/20240513201654/https://cm-sabugal.pt/wp-content/uploads/2024/03/mapa_global_seccao_voto-9.pdf);
  - президентские-2021: [карта](https://arquivo.pt/wayback/20210923115136/https://cm-sabugal.pt/wp-content/uploads/2021/01/mapa-global-por-seccoes-de-voto-7.pdf);
  - муниципальные 2009–2021: [2009](https://arquivo.pt/wayback/20091219115212/https://web.cm-sabugal.pt/files/2009_09/eleicoes09/mapa_global_seccoes_voto.pdf), [итоговая 2021](https://arquivo.pt/wayback/20210930170925/https://cm-sabugal.pt/wp-content/uploads/2021/09/mapaderesultadosdefinitivos_por_seccao_de_voto.pdf).
  Т.е. секционные данные фактически публичны на муниципальном уровне уже давно, без всяких
  запросов; для AR-2025 их надо собирать по 308 камарам (сайты/архивы или запрос — камеры тоже
  подчиняются Lei 26/2016).
- **Поправка прежнего тезиса** («старые порталы до 2015 содержали секции в HTML»): архив это
  НЕ подтверждает. Структура старых порталов MAI — [autarquicas2001](https://arquivo.pt/wayback/20141007173534/http://www.eleicoes.mai.gov.pt/)
  (38 тыс. URL) и [legislativas2015](https://arquivo.pt/wayback/20210928140659/https://eleicoes.mai.gov.pt/legislativas2015/territorio-nacional.html)
  (6,5 тыс. URL, формат `D####/C####/F####.html`) — заканчивается на уровне фрегезии, «secc» в
  URL нет, на архивной странице фрегезии (autárquicas2001, C010100/010100_AF.html) секций нет.
  Централизованная публикация секций, по-видимому, никогда не существовала; «потерян» при
  редизайне максимум доступ к старым статическим сайтам, но не детализация.

### Центральные источники секции НЕ отдают — проверено (09.10.2026)

- Портал MAI, AR-2025: дерево `territory-tree.json` — 4 уровня, 3092 фрегезии, листья; ниже ничего.
- Портал MAI, новый API (шаблон президентских-2026): спуск округ→конселью→фрегезия; фрегезия
  `typeId=7, final=true`, детей 0 — даже новейшие выборы останавливаются на фрегезии.

- По закону (LEAR ст. 115) национальная карта издаётся по округам; обязанности публиковать секции
  централизованно нет — камеры делают это сами (обычай, не требование).
- Агрегаторов не найдено: GitHub-датасетов по секциям нет, портал «dadosabertos.mai.gov.pt» не существует
  (домен не резолвится — появляется только в галлюцинациях поисковых ассистентов).

### Как собирать (методика, если пойдем по всем 308)

1. Список конселью — из `results_concelhos.csv`; сопоставить домены камер (вручную/через Google `camera municipal <nome> site:.pt`).
2. На каждом сайте найти раздел Eleições/Resultados (поиск по сайту, sitemap, Google `site:`).
3. Скачать PDF/XLSX за AR-2025; альтернатива для умерших ссылок — arquivo.pt (у Сабугала 2009–2024 так).
4. Парсинг: `pdftotext -layout` даёт чистые колонки (проверено на Alcácer do Sal); сложную вёрстку — pdfplumber.
5. Контроль качества: суммы секций по фрегезии обязаны сойтись с `results_freguesias.csv` (MAI).
6. Для сопоставления секций между выборами/геопривязки — предвыборные «Mapa definitivo das assembleias
   e secções de voto» (их камеры обязаны публиковать; видеть Trofa, Gaia, Mafra).

## Скрипты для повторного использования (`scripts/`)

```bash
# Старый формат портала (выборы до 2025; темп ~5 req/s, автопауза при бане CDN):
python3 scripts/fetch_mai_results.py legislativas2024          # парламентские
python3 scripts/fetch_mai_results.py europeias2024 --suffix PE # европейские
python3 scripts/fetch_mai_results.py autarquicas2021 --suffix CM,AM,AF  # муниципальные
python3 scripts/fetch_mai_results.py regionais2024 --suffix RA # Азорские о-ва (Мадейра — RM!)
python3 scripts/fetch_mai_results.py legislativas2024 --leaf-level 3     # не проверять фрегезии на детей (быстрее)

# Новый формат портала (autarquicas2025, presidenciais2026_*):
python3 scripts/fetch_mai_results_v2.py presidenciais2026_1S --organs 3
python3 scripts/fetch_mai_results_v2.py autarquicas2025 --organs 4,5,6  # CM+AM+AF

# Собрать сводные CSV из выгрузки (оба формата):
python3 scripts/build_csv.py data/legislativas2024_mai

# Проверить целостность всех выгрузок (суммы листьев против национального итога):
python3 scripts/verify_downloads.py
```

Скрипты умеют докачивать (перезапуск безопасен), сами ждут при блокировке CDN.
Slug'и выборов — из URL портала `eleicoes.mai.gov.pt/<slug>/`; суффиксы: AR (парламент), PE (Европарламент), PR (президент), CM/AM/AF (муниципальные триады).

**Если CDN банит curl** (Access Denied при массовом скачивании — так было в 2025-м):
запасной путь через реальный браузер, чьи запросы Akamai пропускает:
1. `python3 scripts/local_receiver.py <каталог_выгрузки> 8765` — локальный приёмник файлов;
2. открыть в браузере страницу выборов на портале и выполнить в её консоли
   `scripts/browser_loader.js` (подставив список ключей и суффикс) — он скачает всё
   темпом ~1.5 req/с с автопаузами и передаст файлы приёмнику.
