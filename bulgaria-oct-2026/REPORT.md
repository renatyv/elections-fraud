# Болгария: президентские выборы 25.10.2026 — открытые данные и скрейпинг

Дата подтверждена ЦИК: «Избори за президент и вицепрезидент — 25 октомври 2026».
Если никто не наберёт абсолютное большинство — второй тур **8 ноября 2026**.
Выборы только президентские (парламентские досрочные были 19.04.2026).

| Источник | URL | Что там |

`{тур}/protokoli/…` и `opendata/export.zip` (txt с «;»), `opendata/spreadsheet.zip` (xlsx) — выкладываются к концу обработки. Туры: `tur1/`, `tur2/`.

## Как обновляются промежуточные результаты

- Страницы — **статический HTML, перегенерируется** по мере обработки протоколов; обновления всю ночь (в апреле 2026 первая публикация ~21:40, далее каждые десятки минут).
- На странице: статусная строка «Данни към ЧЧ:ММ на ДД.ММ.ГГГГ при обработени **X%** СИК протоколи в РИК» + таблица «№ / Кандидатска двойка / Гласове / Разпределение» + метрики протокола (избиратели, гласували, действителни/недействителни).
- Явка в течение дня: отчёты на **11:00, 16:00 и 20:00**.
- `machine/data.js` (JS-индекс, отдаётся без Cloudflare) меняется чаще HTML — годится как детектор обновлений.
- Ограничение: сайты ЦИК стоят за Cloudflare с интермиттирующим managed-challenge (HTML/zip могут отдавать 403 для не-браузеров, `*.js` — практически всегда доступны). Скрипт применяет каскад `requests → curl_cffi (impersonate chrome) → cloudscraper` с ретраями.

## Скрипты

- `scrape_cik.py` — скрейпер: автоопределение портала 2026 в индексе, опрос `tur1`/`tur2` (результаты, явка, машинные протоколы), сырые снапшоты + CSV-таймлайны.
- `run_every_15min.sh` — обёртка для cron; `requirements.txt` — зависимости (`pip install -r requirements.txt`, venv уже в `.venv/`).

```bash
# цикл с интервалом 15 минут (по умолчанию):
.venv/bin/python scrape_cik.py --loop
# разовый прогон (для cron):
.venv/bin/python scrape_cik.py --once
# тест на выборах 2021 (обоих турах):
.venv/bin/python scrape_cik.py --once --base https://results.cik.bg/pvrns2021/
```

Выход в `data/`: `raw/<время>/` (HTML/JS как есть), `results_timeline.csv` (голоса/доли по парам по времени), `turnout_timeline.csv`, `stats_timeline.csv`, `machine_sections_timeline.csv`, `state.json` (адрес портала, хэши VERSION для детекта «без изменений»), журнал `scrape.log`.

**Проверено 10.10.2026** на живом сайте: тур-1 2021 — Радев 49,42%, Герджиков 22,83%; тур-2 — 66,72% / 31,80%; явка 40,23% / 34,84% — всё совпало с официальными итогами; плоская структура (pe202604) тоже парсится.

## Чек-лист на 25.10.2026

1. Запустить `scrape_cik.py --loop` заранее (например, с утра) — он сам найдёт портал, когда тот появится в индексе, и начнёт писать явку 11:00/16:00/20:00.
2. Первые результаты — ориентировочно после 21:00–21:45; следить за строкой «обработени X%».
3. Финальные машиночитаемые данные — `opendata/export.zip` (txt) и `spreadsheet.zip`; после 100% обработки скачать вручную (zip-файлы скрипт не тянет из-за Cloudflare).
4. Если Cloudflare ужесточат в ночь выборов — при 403 держать открытым браузером `results.cik.bg` и при необходимости поднять интервал (`--interval 300` и более); в пределе — FlareSolverr/Playwright.
