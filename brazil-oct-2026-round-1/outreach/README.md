# Драфты для распространения бразильского анализа

Подготовлено 20 октября 2026 года. Это черновики; сообщения не отправлены.

## Что внутри

- `reddit/brasil-pt.md`: самостоятельный пост на португальском и запрос модераторам.
- `reddit/dataisbeautiful-en.md`: заголовок, источник визуализации и первый комментарий на английском.
- `email/journalists-pt.md`: три отдельных письма редакциям Nexo, Aos Fatos и Agência Pública.
- `email/cepesp-pt.md`: отдельное письмо исследователям, с конкретным вопросом о модели.
- `contacts.md`: адресаты, опубликованные каналы связи, источники и ограничения проверки.

## Перед использованием

Заменить `[URL_DA_ANALISE]` / `[ANALYSIS_URL]` на публичный URL обновлённой страницы и `[SEU_NOME]` на предпочитаемую подпись. Подтверждённого адреса Vercel в доступной документации нет; адрес сайта не придуман. Суффикс страницы: `/brazil-oct-2026-round-1/`. Переключатель языка использует браузер и localStorage: параметр `?lang=pt` сейчас не поддерживается.

Ссылки GitHub взяты из git remote (`renatyv/elections-fraud`, ветка `main`). Перед рассылкой проверить доступность репозитория без авторизации и опубликовать обновлённый текст/графики: текущие изменения локальные. Исходные CSV объёмом около 23 ГБ не обещать как доступное вложение; указывать TSE и инструкции проекта.

Посты опираются на существующие результаты репозитория; в рамках подготовки текстов статистические расчёты и исходные выгрузки TSE заново не проверялись. Сценарий 52,6/47,4 не использовать как основной рекламный заголовок: интервал не охватывает перенос модели между выборами.

## Порядок

1. Запросить методологический отзыв CEPESP; параллельно можно предложить редакциям материал о возможностях и ограничениях статистических проверок.
2. Для Reddit проверить актуальные правила и статус аккаунта. В r/brasil сначала воспользоваться подготовленным modmail, если допустимость собственного материала неясна.
3. Опубликовать один материал и ответить на вопросы. Не копировать одинаковый пост по множеству сообществ.
4. Один follow-up редакции через 5–7 рабочих дней; не писать одновременно нескольким сотрудникам одной редакции.
