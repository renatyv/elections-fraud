# Выборы в Народную скупщину Сербии — 25 октября 2026

**Отчёт:** источники открытых данных + скрипты съёма промежуточных результатов каждые 15 минут.
Подготовлено 10.10.2026. Скрипты проверены на реальных данных выборов-2023 (тур РИК 341140) — цифры совпадают с официальными итогами.

## 2. API РИК (реверс фронтенда официального портала)

Все запросы — POST c заголовком `X-Requested-With: XMLHttpRequest`:

- `/get-elections/` `{election_type: 2}` → туры: `{"680072": "Парламентарни 2026"}`
- `/get-regions/` `{election_type, election_round}` → регионы (+коды NUTS2)
- `/get-municipalities/` `{..., election_region}` → HTML-опции муниципалитетов
- `/get-election-stations/` `{..., election_municipality}` → участки
- `/get_results/` `{type=2, election_round, region, municipality, election_station}` → ответ:

```
stat_sum_numbers: total_voters, available (проголосовало), processed_stations,
                  number_of_stations, datetime (метка данных РИК), election_title
table_data:       [{list_name, won_number, won_percent}, ...]
sum_config:       данные диаграммы → действительные/недействительные бюллетени
```

Особенности: числа с точками-разделителями («3.820.746»), кириллица, `datetime` служит меткой обновления (для дедупликации), поле `available` = число проголосовавших.

## 3. Скрипты (только stdlib Python 3, без зависимостей)

| Файл | Назначение |
|---|---|
| `scripts/rik_api.py` | клиент API: запросы, разбор чисел/дат, нормализация |
| `scripts/scrape_rik.py` | съём: снапшоты raw-JSON + CSV-таймлайны, цикл `--loop` |
| `scripts/latest_summary.py` | сводка: текущее положение, Δ с прошлого снапшота (`--html` → md) |
| `scripts/run_scraper.sh` | обёртка для cron (разовый проход) |
| `scripts/com.user.serbia-rik-scraper.plist` | LaunchAgent macOS на 15 минут |

**Запуск (15 минут):**

```bash
# вариант А — встроенный цикл
python3 scripts/scrape_rik.py --loop --interval 900

# вариант Б — cron
*/15 * * * * "<путь>/scripts/run_scraper.sh" >> "<путь>/data/cron.log" 2>&1

# вариант В — macOS launchd
cp scripts/com.user.serbia-rik-scraper.plist ~/Library/LaunchAgents/ && \
launchctl load ~/Library/LaunchAgents/com.user.serbia-rik-scraper.plist
```

Уровни: по умолчанию `--levels national,regions`; муниципалитеты добавить флагом `--levels national,regions,municipalities` (~180 запросов за проход). Сводка в конце дня: `python3 scripts/latest_summary.py --html`.

**Данные:** `data/raw/<тур>/<дата_время>/*.json` (исходники), `data/timeline/<тур>/snapshots_national.csv` (явка/участки по снапшотам), `results_long.csv` (голоса списков по всем уровням). Снапшот пишется только при изменении метки `datetime` РИК — пустых дублей не будет. В `data/` уже лежит валидационная выборка по туру 341140 (выборы-2023).

## 4. Замечания

- API не документировано официально — это внутренний протокол портала результатов РИК; формат стабилен (тот же с 2020 г.), но перед ночью выборов стоит прогнать тестовый проход.
- robots.txt у РИК нет; интервал 15 минут и паузы между запросами — заведомо вежливая нагрузка.
- Время в данных — местное сербское (CET/CEST). Порог прохождения списков — 3%. 250 мандатов, страна — единый округ.
- Для истории/архива: финальные Excel-выгрузки РИК традиционно появляются в разделе «Документа» после объявления итогов; протоколы РГ-2 доступны по API по каждому участку.
