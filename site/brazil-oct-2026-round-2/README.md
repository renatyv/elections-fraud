# Brazil, presidential runoff 25.10.2026 — statistical fraud check

**Состояние на 26.10.2026 — предварительная версия страницы.** TSE ещё не
опубликовал послетурнюю выгрузку по секциям (CDN отдаёт генерацию от 06/10,
строк `NR_TURNO=2` нет), поэтому страница показывает предварительные результаты:
динамику вечера выборов по 13 снимкам портала, декомпозицию сдвига по штатам и
проверку условного сценария 1-го тура против фактического итога. Блок
посекционной криминалистики заменён панелью «pending»; полный анализ появится
после публикации данных ТСЕ.

Полная (финальная) версия страницы — шаблон с ⟦TOKEN⟧-заполнителями — сохранена
в `brazil-oct-2026-round-1/site_round2_template/` (`index.html` +
`translations.js`). Когда выгрузка появится: восстановить шаблон, прогнать
пайплайн (см. ниже) и `fill_page_tokens.py`.

Раздел сайта репозитория (`<репо>/site/brazil-oct-2026-round-2/`): статическая
одностраничка по отчётам [REPORT_statistical_fraud_analysis_T2.md](../../brazil-oct-2026-round-1/REPORT_statistical_fraud_analysis_T2.md)
и [PARADOXES.md](../../brazil-oct-2026-round-1/PARADOXES.md) (§ о 2-м туре).
Без сборки и зависимостей: `index.html` + `img/<lang>/*.png` и
`img/details/<lang>/*.png`; главные графики строит
`brazil-oct-2026-round-1/scripts/build_site_figures_T2.py`, детальные —
`run_forensics_T2.py --fig-out` и `control_forensics_T2.py --fig-out` (по разу
на язык). Предварительная тройка графиков (counting, swing, prediction × 4
языка) — `scripts/build_site_figures_T2_prelim.py`; финальная сборка их
перезапишет.

Языки: Português, English, Español, Русский — переключатель в шапке, при первом
входе выбирается язык браузера, выбор запоминается в localStorage (ключ общий с
титульной страницей); вместе с текстом подменяются и картинки.
Структура — пирамида Минто: вывод с ограничениями (+ карточка провала
условного сценария 1-го тура: модель по перетокам 2022 дала Лулу 47,43%,
фактически 51,79%) → ситуация (итог 2-го тура, ночь подсчёта,
губернаторские 2-е туры) → естественный эксперимент `#paradoxes` (фактическая
матрица перетоков 2026, проверка сценария, динамика апурации + декомпозиция
сдвига по партиям штатов) → результаты
тестов на манипуляции (11 семейств, графики в раскрывающихся карточках) →
ограничения → данные.

## Публикация на Vercel

Сайт репозитория деплоится целиком от корня `site/` — разделы-страны лежат
рядом (`site/brazil-oct-2026-round-2/`). Статика без конфига:

```bash
cd site
npx vercel            # из каталога site/ (прод: npx vercel --prod)
```

или drag-and-drop каталога `site/` на [vercel.com/new](https://vercel.com/new),
или импорт Git-репозитория с Root Directory = `site`.
