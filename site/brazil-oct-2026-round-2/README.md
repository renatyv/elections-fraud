# Brazil, presidential runoff 25.10.2026 — statistical fraud check

Раздел сайта репозитория (`<репо>/site/brazil-oct-2026-round-2/`): статическая
одностраничка по отчётам [REPORT_statistical_fraud_analysis_T2.md](../../brazil-oct-2026-round-1/REPORT_statistical_fraud_analysis_T2.md)
и [PARADOXES.md](../../brazil-oct-2026-round-1/PARADOXES.md) (§4-b о 2-м туре).
Финальная версия (27.10.2026): посекционная криминалистика 2-го тура выполнена
по выгрузке TSE от 26–27.10 (все проверки сходимости нулевые, итоги совпадают с
ночной записью портала до последнего голоса).

Без сборки и зависимостей: `index.html` + `img/<lang>/*.png` (9 главных
графиков × 4 языка) и `img/details/<lang>/*.png` (16 детальных × 4 языка).
Главные графики строит `brazil-oct-2026-round-1/scripts/build_site_figures_T2.py`,
детальные — `run_forensics_T2.py --fig-out` и `control_forensics_T2.py
--fig-out` (по разу на язык; в details-каталогах остаются только *.png).
Числа в тексте запечены в `translations.js` (162 ключа × 4 языка) синхронно с
`analysis_T2/metrics_T2.json`, `metrics_control_T2.json` и
`analysis/paradox/prediction_vs_actual.json` на дату сборки.

Языки: Português, English, Español, Русский — переключатель в шапке, при первом
входе выбирается язык браузера, выбор запоминается в localStorage (ключ общий с
титульной страницей); вместе с текстом подменяются и картинки.
Структура — пирамида Минто: вывод (+ карточка провала условного сценария 1-го
тура: модель по перетокам 2022 дала Лулу 47,43%, фактически 51,79%) → ситуация
(итог 2-го тура, ночь подсчёта, губернаторские 2-е туры) → естественный
эксперимент `#paradoxes` (проверка сценария, фактическая матрица перетоков 2026
с таблицей вкладов в промах 4,36 п.п., динамика апурации + декомпозиция сдвига
по партиям штатов) → результаты тестов на манипуляции (11 семейств, графики в
раскрывающихся карточках; Benford — единственная с бейджем «≠»: формальное
отвержение повторяет структурный артефакт 1-го тура) → ограничения → данные.

## Публикация на Vercel

Сайт репозитория деплоится целиком от корня `site/` — разделы-страны лежат
рядом (`site/brazil-oct-2026-round-2/`). Статика без конфига:

```bash
cd site
npx vercel            # из каталога site/ (прод: npx vercel --prod)
```

или drag-and-drop каталога `site/` на [vercel.com/new](https://vercel.com/new),
или импорт Git-репозитория с Root Directory = `site`.
